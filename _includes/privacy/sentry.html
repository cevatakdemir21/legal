Crash and error reporting (Sentry)

{{ page.app_name }} uses Sentry to report crashes and errors, so that faults can be diagnosed and fixed.

A crash report contains:

  • the technical stack trace describing where in the code the failure occurred;
  • app version, device model, operating system version, and device state at the time (such as free memory);
  • a randomly generated installation identifier, so repeated reports from one device can be grouped.

Crash reports are not intended to contain the content you create. We do not attach your data to reports, and we do not send Sentry your name or email address. Because a stack trace is generated automatically at the moment of failure, we cannot guarantee that a fragment of data is never included incidentally; where that is possible we configure Sentry’s data-scrubbing to remove it.

Functional Software, Inc. (Sentry) acts as our data processor and provides protection for this data equal to that described in this policy; see the Sentry Privacy Policy. Reports are retained for a limited period and then deleted automatically.
